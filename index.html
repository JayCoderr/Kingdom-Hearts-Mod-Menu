Kingdom Hearts Modding Index

The Kingdom Hearts Modding Index is a research and reference database dedicated to understanding the internal data and systems behind the Kingdom Hearts PC games.

This site documents information discovered through reverse engineering, game-data research, memory research, Cheat Engine experimentation, asset analysis and hands-on modding.

A major focus of the project is understanding the game's data files and the way different assets, identifiers, variables and resources are organized and used by the game.

What You'll Find Here

The Index brings together research and documentation covering characters, worlds, internal identifiers, variables, assets, file formats, tools and other information useful for Kingdom Hearts modding.

Some of this information comes from direct experimentation and reverse engineering, while other information is built through examining game files, testing values in-game, analyzing assets and comparing discovered data.

The goal is to turn scattered discoveries into organized documentation that can be referenced by other modders and researchers.

Research & Reverse Engineering

This database covers research involving game memory, Cheat Engine, executable behavior, internal variables, character data, world data, asset structures and the relationships between the different systems used by the game.

It also documents findings from investigating Kingdom Hearts data archives and individual file types, including BIN, HED, PKG, WPN, DAT, DDS, MDLX, MDLS, TM2, MSET and other resources.

Asset Hashing & Cross-Reference Research

Asset identification and hashing is another part of the research documented by this Index.

During the investigation of Kingdom Hearts assets, information from the OpenKH project was used as a reference for cross-referencing asset hashes and identifying relationships between hashed resources and their corresponding game assets.

These references were then compared against independently examined game files and in-game behavior to help verify and document the information within this database.

OpenKH is credited as a reference for the relevant hashing and asset-identification information. The Index is intended to build upon that research through additional experimentation, verification and documentation.

An Ongoing Reference

This is an ongoing research project. New discoveries, identifiers, file structures, tools and documentation will be added as the game's data is investigated further.

The information presented here is intended to help people understand how Kingdom Hearts works internally and provide a foundation for creating and researching mods.
